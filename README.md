> 🎯 A modern, feature-rich e-commerce web application built with the MERN stack (MongoDB, Express.js, React, Node.js)

---

## ✨ Features

### 🛒 Shopping Experience
- ⭐ **Product Browse** - Explore products with advanced filters
- 🔍 **Smart Search** - Powerful search functionality
- 💳 **Secure Checkout** - Safe and secure payment processing
- ❤️ **Add to Cart** - Add products in your cart

### 👤 User Management
- 🔐 **Authentication** - Secure user registration and login
- 👥 **User Profiles** - Manage personal information and preferences
- 📦 **Order History** - View all past purchases
- 📍 **Multiple Addresses** - Save and manage delivery addresses
- ⚙️ **Account Settings** - Customize your experience

### 🏪 Admin Dashboard
- 📊 **Sales Analytics** - View sales trends and insights
- 📦 **Inventory Management** - Manage product stock levels
- 👥 **User Management** - Handle user accounts and permissions
- 💰 **Payment Tracking** - Monitor all transactions
